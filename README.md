# 탐욕과 기억

8원을 1·4·6원 동전으로 주면? — 지금 가장 좋아 보이는 것을 고르는 탐욕 알고리즘과, 계산한 것을 기억하며 푸는 동적계획법을 비교하는 앱입니다. 거스름돈(이상한 나라 vs 우리나라 동전), 크루스칼 최소 신장 트리, 가까운 곳부터 가는 배송 경로 vs 720가지 최단, 순서의 수 폭발, 피보나치 호출 횟수와 호출 나무, 공장 시간 배낭 문제의 표 채우기까지 손으로 체험합니다. 지능 03 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 거스름돈: 동전 체계·금액별 탐욕 vs 최선 동전 비교, 퀴즈 ①, 탐욕이 통하는 두 조건
- ② 연결·배송: 크루스칼 단계 실행(고리 건너뛰기), 배송 경로 탐욕 vs 최단(새 지도 가능), n! 순서의 수
- ③ 기억하기: 피보나치 호출 횟수(기억 없이 vs 메모이제이션), 호출 나무, 퀴즈 ②, 하향식 vs 상향식
- ④ 공장 시간: 작업 시간·이익 편집, 시간당 이익 탐욕 vs 동적계획법 표 채우기와 되짚기, 한계, 세 줄 정리, 생각해 볼 질문
